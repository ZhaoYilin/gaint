Basis Sets and Gaussian Functions

GaInt supports Cartesian Gaussian Type Orbitals (GTOs), which are atomic orbitals used in linear combinations to form molecular orbitals. Cartesian GTOs are defined by an angular part that is a homogeneous polynomial in the components x, y, and z of the position vector \(\mathbf{r}\). The mathematical definition is:

\[ G_{ijk}(r_A,\alpha) = x^i_A y^j_A z^k_A e^{-\alpha r^2_A} \]

Where:

  • \(r_A = r - A\) is the atom-centered function

  • \(\alpha > 0\) is the real orbital exponent

  • \(i+j+k = n\) is the total angular momentum quantum number

Most mainstrem quantum chemistry packages use the same basis set input file format as NWChem, one can download them from the EMSL Basis Set Exchange website (https://bse.pnl.gov/bse/portal).

Primitive Gaussian Type Orbital

Most quantum chemistry packages support Contracted Gaussian Type Orbitals (CGTOs), which are atomic orbitals formed by linear combinations of Primitive Gaussian Type Orbitals (PGTOs). In this notebook, we focus on integrals over primitive Gaussian type orbitals, which are defined by an angular part that is a homogeneous polynomial in the components x, y, and z of the position vector \(\mathbf{r}\). The mathematical definition is:

\[ G_{ijk}(r_A,a) = x^i_A y^j_A z^k_A e^{-a r^2_A} \]

  • a>0 is the orbital exponent.

  • \(r_A = r − A\) is the electronic coordinate.

  • i ≥ 0, j ≥ 0, k ≥ 0 is the quantum number.

  • Total angular-momentum quantum number l = i + j + k ≥ 0

Cartesian Gaussians can be factorized into three Cartesian directions:

\[ G_{ijk}(r_A,a) = G_i(r_A,a)G_j(r_A,a)G_k(r_A,a) \]

where

\[ G_i(r_A,a)= x^i_A e^{-a x^2_A} \]

Gaussians satisfy a simple recurrence relation:

\[ x_A G_i(a, x_A ) = G_{i+1}(a, x_A ) \]

The differentiation of a Gaussian yields a linear combination of two Gaussians

\[ \frac{\partial G_i(a, x_A )}{\partial A_x} = -\frac{\partial G_i(a, x_A)}{\partial x} = 2aG_{i+1}(a, x_A) − iG_{i−1}(a, x_A) \]

An important property of Gaussians is the Gaussian product rule. The product of two Gaussians is another Gaussian centered somewhere on the line connecting the original Gaussians; its exponent is the sum of the original exponents:

\[ e^{-a x^2_A} e^{-b x^2_B} = e^{-\mu X_{AB}^2} e^{-p x^2_P} \]

while the centre-of-charge \(P_x\) and the relative coordinate or Gaussian separation \(X_{AB}\) are given by

\[\begin{split} \begin{aligned} p &= a+b\\ \mu &= \frac{ab}{a+b}\\ P_x &= \frac{aA_x+bB_x}{a+b}\\ X_{AB} &= A_x - B_x \end{aligned} \end{split}\]
